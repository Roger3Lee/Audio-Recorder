# 🔒 AudioRecorder 互斥功能说明

## 📋 **功能概述**

AudioRecorder 现在支持**单实例运行**，确保同一时间只能运行一个应用程序实例，避免资源冲突和重复操作。

## 🚀 **主要特性**

### 1. **单实例保护**
- 使用 Windows 系统级互斥锁（Mutex）
- 全局唯一标识符：`Global\AudioRecorder_SingleInstance_Mutex`
- 防止多个实例同时运行

### 2. **智能实例管理**
- 检测已运行的实例
- 自动激活现有实例
- 显示友好的用户提示

### 3. **窗口激活功能**
- 恢复最小化的窗口
- 将窗口置于前台
- 确保用户能看到应用程序

## 🔧 **技术实现**

### **互斥锁机制**
```csharp
// 创建全局互斥锁
private const string MUTEX_NAME = "Global\\AudioRecorder_SingleInstance_Mutex";
private static Mutex? _mutex;
private static bool _isFirstInstance = false;

// 尝试获取互斥锁
_mutex = new Mutex(true, MUTEX_NAME, out _isFirstInstance);
```

### **实例检测逻辑**
```csharp
if (!_isFirstInstance)
{
    // 已有实例在运行
    MessageBox.Show("AudioRecorder 已经在运行中！");
    ActivateExistingInstance();
    return;
}
```

### **窗口激活 API**
```csharp
[DllImport("user32.dll")]
private static extern bool ShowWindow(IntPtr hWnd, int nCmdShow);

[DllImport("user32.dll")]
private static extern bool SetForegroundWindow(IntPtr hWnd);

[DllImport("user32.dll")]
private static extern bool IsIconic(IntPtr hWnd);
```

## 🔍 **故障排除**

### **常见问题**

#### 1. **互斥锁无法创建**
- **原因**：权限不足或系统资源问题
- **解决**：以管理员身份运行，或重启应用程序

#### 2. **窗口激活失败**
- **原因**：窗口句柄无效或权限限制
- **解决**：检查进程状态，必要时重启应用程序

#### 3. **进程检测不准确**
- **原因**：进程名称匹配问题
- **解决**：确认可执行文件名为 `AudioRecorder.exe`
