# 📝 AudioFileUploadService 日志记录增强

## 📋 **概述**

为 `AudioFileUploadService` 添加了全面的日志记录功能，使用 `Microsoft.Extensions.Logging` 框架，提供详细的上传过程跟踪和故障排除信息。

## 🔍 **增强内容**

### 1. **服务初始化日志**
- 记录服务初始化开始和完成
- 记录上传配置参数（重试次数、延迟、超时）
- 记录 HTTP 客户端配置状态

**日志示例**：
```
[INFO] AudioFileUploadService 初始化开始
[INFO] 上传设置: 重试次数=3, 重试延迟=5000ms, 超时=30000ms
[INFO] HTTP客户端配置完成，请求头已设置
[INFO] AudioFileUploadService 初始化完成
```

### 2. **文件验证日志**
- 记录文件验证过程
- 记录文件大小信息
- 详细的错误信息和路径

**日志示例**：
```
[INFO] 开始上传音频文件流程
[INFO] 文件验证通过，准备上传: 系统音频=system_audio.wav(1024000字节), 麦克风=microphone.wav(512000字节)
```

### 3. **上传重试流程日志**
- 记录每次重试尝试的开始和结果
- 记录重试延迟和等待时间
- 记录达到最大重试次数的情况

**日志示例**：
```
[INFO] 开始重试上传流程，最大重试次数: 3
[INFO] 开始上传尝试 1/3
[INFO] 上传尝试 1 成功
```

### 4. **HTTP 请求详细日志**
- 记录请求准备过程
- 记录文件添加到表单的详细信息
- 记录业务参数设置
- 记录 API URL 和授权信息
- 记录请求耗时和响应状态
- 记录响应头和响应内容

**日志示例**：
```
[INFO] 准备单次上传尝试
[DEBUG] 已添加系统音频文件到表单: system_audio.wav
[DEBUG] 已添加业务参数: bizType=recording, mergeAudio=true
[INFO] 准备发送HTTP请求到: https://api.example.com/upload
[INFO] HTTP请求完成，耗时: 1250ms, 状态码: 200
[INFO] 响应头: Content-Type=application/json, Server=nginx
```

### 5. **事件触发日志**
- 记录所有事件触发的详细信息
- 区分不同日志级别（Debug、Info、Warning、Error）

**日志示例**：
```
[DEBUG] 触发上传进度变化事件: 📤 上传尝试 1/3...
[INFO] 触发上传完成事件: ✅ 音频文件上传成功！
[ERROR] 触发上传错误事件: 网络连接超时
```

### 6. **资源释放日志**
- 记录服务销毁过程
- 记录 HTTP 客户端释放状态
- 异常处理和错误记录

**日志示例**：
```
[INFO] AudioFileUploadService 开始释放资源
[INFO] HTTP客户端已释放
[INFO] AudioFileUploadService 资源释放完成
```

## 🎯 **日志级别使用**

### **Information 级别**
- 服务生命周期事件（初始化、销毁）
- 重要的业务操作（开始上传、上传成功）
- 配置信息记录

### **Warning 级别**
- 重试过程中的失败
- HTTP 请求失败（非异常情况）
- 达到最大重试次数

### **Error 级别**
- 文件验证失败
- 网络异常
- 资源释放错误
- 未预期的异常

### **Debug 级别**
- 详细的请求准备过程
- 事件触发信息
- 参数设置详情

## 📊 **日志信息结构**

### **结构化日志参数**
使用结构化日志记录，便于日志分析和查询：

```csharp
_logger.LogInformation("文件验证通过，准备上传: 系统音频={SystemAudio}({Size}字节), 麦克风={Microphone}({Size}字节)", 
    Path.GetFileName(systemAudioPath), systemAudioInfo.Length,
    Path.GetFileName(microphonePath), microphoneInfo.Length);
```

### **性能监控信息**
- 请求耗时记录
- 文件大小信息
- 重试次数统计

### **错误上下文信息**
- 完整的异常堆栈
- 相关的文件路径
- 操作状态信息

## 🔍 **故障排除**

### **常见问题诊断**

#### 1. **上传失败分析**
通过日志可以快速定位问题：
- 文件验证阶段：检查文件路径和大小
- 网络请求阶段：检查 API URL 和授权
- 重试阶段：检查重试策略和延迟

#### 2. **性能问题分析**
- 请求耗时异常：检查网络状况
- 文件大小异常：检查音频文件质量
- 重试次数过多：检查服务器稳定性

#### 3. **配置问题分析**
- 超时设置：检查网络环境
- 重试策略：检查业务需求
- 授权令牌：检查认证状态
